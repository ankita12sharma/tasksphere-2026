# 🚀 Task Sphere

Task Sphere is a full-stack MERN Task Management application built to help users organize, manage and track daily tasks through a clean and responsive dashboard interface.
The project includes authentication, task management features, filtering functionality and responsive UI components designed using both Material UI and simple CSS styling.

---

## ✨ Features

- 🔐 User Authentication (Login & Signup)
- 📝 Add, Edit & Delete Tasks
- 📌 Priority-Based Task Management
- ✅ Task Status Tracking
- 🔍 Search Functionality
- 🎯 Filter & Sort Tasks
- 📊 Dashboard Summary Cards
- 📱 Responsive User Interface
- ⚡ Real-Time UI Updates
- 🔒 JWT Authentication & Protected Routes

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- RTK Query
- Material UI (MUI)
- React Router DOM
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt.js

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ankita12sharma/tasksphere-2026.git
```

---

### 2️⃣ Navigate to the Project Folder

```bash
cd tasksphere-2026
```

---

### 3️⃣ Install Dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd ../server
npm install
```

---

## 🔐 Environment Variables

Create a `.env` file inside the `server` folder and add:

```env
MONGO_CONN=your_mongodb_connection_string
JWT_TOKEN=your_secret_key
```

---

## ▶️ Run the Application

### Start Backend Server

```bash
cd server
npm start
```

### Start Frontend

```bash
cd client
npm run dev
```
